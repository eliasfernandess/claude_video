# A escada: texto pronto para a ElevenLabs

Cada bloco abaixo é **um clipe**: cole na ElevenLabs, gere, baixe e salve com o número do clipe (`01_namiques.mp3`, `02_namiques.mp3`…). Depois é só montar na ordem no editor (CapCut, Premiere etc.).

- As tags entre colchetes, em inglês (`[softly]`, `[sighs]`…), são **audio tags**. Elas só funcionam nos modelos **Eleven v3 / v4**. Se usar o Multilingual v2, apague as tags.
- **Pausas:** v3 e v4 não aceitam `<break>`. As pausas vêm da pontuação (`…`, `—`, ponto final). Pausas longas (2 s ou mais) ficam melhores **feitas na edição**: é só deixar um silêncio entre os clipes.
- Gere cada clipe 2 ou 3 vezes e escolha a melhor tomada. A IA varia bastante entre uma geração e outra.

## VOZ 1: NAMIQUES

**Perfil da voz:** masculina, jovem adulta (25–35), português do Brasil, calma, um pouco rouca, de quem está contando um segredo.
**Narração (off):** tom de lembrança, ritmo médio.
**Quebras da quarta parede (👁):** mais perto do microfone, mais baixo e mais lento, como se falasse com uma pessoa só.

### 01: Gancho
```
[softly] E se existisse uma escada que levasse até o seu maior sonho… mas cada degrau só aparecesse quando você deixasse alguma coisa pra trás?
```

### 02 👁: Apresentação
```
[intimate, slow] Pra mim, existiu. Meu nome é Namiques. E antes de você continuar rolando o feed… fica. Eu vou te contar quanto custa cada degrau.
```

### 03: Primeiros degraus
```
No começo, foi fácil. Eu deixei algumas horas de sono. Uns domingos. O medo de tentar. [lightly amused] Meu vizinho deixou o videogame. Mas desceu pra buscar no mesmo dia.
```

## EFEITOS SONOROS (ElevenLabs › Sound Effects)

Gere **um** toc e use o mesmo arquivo nas três vezes. A repetição é o que dá o efeito de reconhecimento.

| Arquivo | Prompt para colar |
|---|---|
| `sfx_toc.mp3` | `three slow soft knocks on a wooden railing, intimate, close microphone, dry room` |
| `sfx_toc_porta.mp3` | *(use o mesmo `sfx_toc.mp3`, com um pouco de reverb no editor)* |
| `sfx_toc_tela.mp3` | `three soft taps on a glass phone screen, very close, intimate` *(ou o mesmo toc com o grave cortado)* |
| `sfx_celular.mp3` | `phone vibrating on a wooden table, two short buzzes` |
| `sfx_vento.mp3` | `gentle night wind at a high place, calm, ambient loop` |
